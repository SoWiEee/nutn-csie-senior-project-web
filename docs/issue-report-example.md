# 網站問題回報範例

以下是**虛構示範**，只用來展示描述方式，不代表網站目前存在這項問題。

## 標題

`[顯示問題] 手機 Safari：時程表卡片標題被截斷`

## 問題簡述

手機版時程表中，較長的專題題目右側文字沒有完整顯示。

## 問題類型

顯示／排版

## 發生問題的頁面網址

`https://example.com/#schedule`（示範網址）

## 裝置與瀏覽器

- 裝置：iPhone／iPad
- 瀏覽器與系統：Safari、iOS（請填實際版本；此處為示範）

## 重現步驟

1. 使用手機開啟時程表分頁。
2. 切換到任一組議程。
3. 找到標題較長的議程卡片並查看右側文字。

## 預期結果與實際結果

- 預期：專題題目完整顯示，或能以合理方式換行。
- 實際：右側部分文字看起來被裁切。

## 發生頻率

每次都會發生（示範）

## 截圖或錄影

可附上裁切位置的截圖；上傳前先遮蔽通知、帳號或其他私人資訊。

## 回報小提醒

- 一個 Issue 優先描述一個問題；不同問題請分開回報。
- 標題寫清楚「問題類型＋裝置／頁面＋現象」。
- 若問題偶爾才發生，補充大約發生時間與當時操作。
- 公開 Issue 不要放學號、聯絡方式、未公開專題資料、密碼、Token 或未遮蔽的瀏覽器資料。
